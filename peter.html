How the Peter Answers game works

A JavaScript activity for a Tecmilenio high school class

This is a playful version of the classic Peter Answers / Peter Answers game. It does not use artificial intelligence: it is a keyboard-event trick built with JavaScript for classroom learning.

How to play

  1. In 1. Game prompt, press the period key (.).
  2. Type the hidden answer you want the game to reveal (for example, Blue).
  3. Your typing is replaced on screen by a decoy phrase: "Peter, please answer this question:".
  4. Press period again to end secret mode, then finish the prompt normally.
  5. Type a question in the second field and click Ask Peter. The game reveals your hidden answer.

JavaScript concepts in the code

  • `keydown` event listener: Captures each key before it appears in the input.
  • `e.preventDefault()`: Cancels the key's default action.
  • Memory variables: Stores the real answer in secretAnswer while displaying decoy text.
