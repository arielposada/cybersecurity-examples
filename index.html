Callbacks: el código que espera su momento

¿Cómo sabe una página cuándo hiciste clic, copiaste algo o seleccionaste texto? La respuesta está en los eventos y las funciones callback.

Guía para bachilleratoLectura: 5 minutosIncluye 2 experimentos

Imagina que pides una pizza y dejas tu número de teléfono. No necesitas llamar cada minuto para preguntar si ya llegó. La pizzería te avisará cuando esté lista. Una función callback trabaja con una idea parecida: es una función que entregas a otro código para que la ejecute cuando corresponda.

¿Qué es un evento?

Un evento es algo que ocurre dentro de la página: hacer clic, presionar una tecla, copiar texto o seleccionar un fragmento. JavaScript puede escuchar estos eventos y responder.

Evento → se activa un listener → se ejecuta el callback

En HTML se encuentran atributos como onclick u oncopy, pero para separar el contenido del comportamiento, normalmente usamos addEventListener() desde JavaScript.

Un ejemplo en tres líneas

const boton = document.querySelector('#saludar');
boton.addEventListener('click', function () {
  alert('¡Hola, clase!');
});

El navegador guarda la función y la ejecuta después, cuando ocurre el clic. Esa función entregada como argumento es el callback. Observa que no escribimos function() {...}(): eso la ejecutaría inmediatamente.

Pista: el navegador también pasa un objeto event al callback, con información sobre lo que sucedió.

Palabras clave

Evento: una acción detectada por el navegador.

Listener: código que se mantiene atento a un evento.

Callback: función que se ejecuta en respuesta.

Clipboard: portapapeles donde se guarda lo que copias.

01 / Evento copy

Copiar no siempre es copiar

Selecciona la oración en inglés y cópiala usando Ctrl+C (o ⌘+C en Mac). Después, pégala en el cuadro o en un editor de texto.

Try to copy this text and paste it somewhere like a text editor
Esperando a que copies el texto…
copySource.addEventListener('copy', (event) => {
  event.preventDefault();
  event.clipboardData.setData('text/plain',
    'See what I mean?, you copied this text instead of the original text'
  );
});

¿Qué sucedió? preventDefault() cancela la copia normal y clipboardData.setData() escribe otro texto en el portapapeles.

02 / Evento mouseup + selección

El texto que te descubre

Selecciona con el mouse una parte de la oración de abajo. Abre la consola con F12 → Console para ver el mensaje.

Subraya o selecciona esta oración con tu cursor y mira qué sucede en la consola del navegador.
Todavía no has seleccionado texto aquí.
selectSource.addEventListener('mouseup', () => {
  if (window.getSelection().toString().trim()) {
    console.log('Hey, I now you just selected the text');

El evento mouseup ocurre al soltar el botón del mouse. getSelection() comprueba que realmente hayas seleccionado texto. También se contempla la selección con teclado.
Para pensar

¿Qué aprendimos?

  1. Un callback es una función que otra parte del programa ejecuta cuando corresponde.
  2. addEventListener() conecta un evento con una función.
  3. El callback puede consultar el evento y, en ocasiones, modificar el comportamiento normal del navegador.
