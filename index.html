Callbacks: the code that waits its turn

How does a page know when you clicked, copied something, or selected text? The answer lies in events and callback functions.

High school guideReading time: 5 minutesIncludes 2 experiments

Imagine that you order a pizza and leave your phone number. You do not need to call every minute to ask whether it has arrived. The pizzeria will let you know when it is ready. A callback function works with a similar idea: it is a function you give to other code so it can run it when appropriate.

What is an event?

An event is something that happens within the page: clicking, pressing a key, copying text, or selecting a fragment. JavaScript can listen for these events and respond.

Event → a listener is activated → the callback runs

HTML includes attributes such as onclick and oncopy, but to separate content from behavior, we normally use addEventListener() from JavaScript.

An example in three lines

const button = document.querySelector('#saludar');
button.addEventListener('click', function () {
  alert('Hello, class!');
});

The browser stores the function and runs it later, when the click occurs. That function passed as an argument is the callback. Notice that we do not write function() {...}(): that would run it immediately.

Tip: the browser also passes an event object to the callback, with information about what happened.

Key terms

Event: an action detected by the browser.

Listener: code that stays alert for an event.

Callback: a function that runs when appropriate.

Clipboard: the place where copied content is stored.

Two events, two surprises

Try each experiment. Then review its JavaScript snippet and explain to a classmate what triggered the function.

01 / Copy event

Copying is not always copying

Select the English sentence and copy it using Ctrl+C (or ⌘+C on Mac). Then paste it into the box or a text editor.

Try to copy this text and paste it somewhere like a text editor
Waiting for you to copy the text…
copySource.addEventListener('copy', (event) => {
  event.preventDefault();
  event.clipboardData.setData('text/plain',
    'See what I mean?, you copied this text instead of the original text'
  );
});

What happened? preventDefault() cancels the normal copy and clipboardData.setData() writes different text to the clipboard.

02 / Mouseup event + selection

The text that gives you away

Use your mouse to select part of the sentence below. Open the console with F12 → Console to see the message.

Underline or select this sentence with your cursor and see what happens in the browser console.
You have not selected any text here yet.
selectSource.addEventListener('mouseup', () => {
  if (window.getSelection().toString().trim()) {
    console.log('Hey, I know you just selected the text');
  }
});
The mouseup event occurs when you release the mouse button. getSelection() checks that you actually selected text. Keyboard selection is also supported.
Food for thought

What did we learn?

  1. A callback is a function that another part of the program runs when appropriate.
  2. addEventListener() connects an event to a function.
  3. The callback can inspect the event and sometimes change the browser's normal behavior.
