Web programming / Privacy

Your browser is talking

Every webpage receives a small collection of clues from your browser. This page lets you inspect them—and learn what JavaScript cannot simply see.

High school guideReading time: 6 minutesNo special permissions requested

When you visit a webpage, your browser has to describe its environment so the page can work. JavaScript can read many ordinary browser properties: the language you prefer, your screen size, the browser family, and whether you are online. These clues are useful for accessibility and layout, but they can also contribute to a browser fingerprint.

Permission-free does not mean invisible

“No special permissions” means this lesson does not ask for your camera, microphone, location, notifications, or files. It can still read information that browsers routinely expose to every page. Modern browsers deliberately limit or reduce some details, so results vary by browser, device, and privacy settings.

Browser APIs → page-readable clues → a partial picture, not your identity

An IP address is different. A page's JavaScript cannot directly ask the browser for your public IP address. The web server can see the network address used to connect, and a page could ask an external server to report it, but this lesson makes no such request.

The basic idea

const browser = navigator.userAgent;
const screenSize = `${screen.width} × ${screen.height}`;
const zone = Intl.DateTimeFormat().resolvedOptions().timeZone;

console.log({ browser, screenSize, zone });

The values above are clues supplied by browser APIs. They should not be treated as proof of a person's identity, exact location, or operating system: browsers can hide, simplify, or spoof them.

Key terms

Browser API: a built-in interface that lets a page ask the browser for information or services.

Fingerprint: a combination of clues that may help distinguish one browser from another.

Permission: a user's approval for more sensitive capabilities, such as location or a camera.

Food for thought

What did we learn?

  1. JavaScript can read ordinary browser and device clues without requesting special permissions.
  2. An IP address is normally known by the server, not exposed as a direct browser property.
  3. A collection of clues may form a fingerprint, but clues are not the same as a person's identity.
  4. Good privacy habits include checking permissions, limiting unnecessary sharing, and understanding what a site can observe.
